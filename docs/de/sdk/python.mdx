## Soberano-Modus (Sie behalten 100%)

Bringen Sie Ihren eigenen Lightning-Anbieter mit — Zahlungen gehen direkt an Ihre Wallet, 0% Gebühren.

```python
import os
from fastapi import FastAPI, Request
from l402kit import l402_required
from l402kit.providers.blink import BlinkProvider

app = FastAPI()

lightning = BlinkProvider(
    api_key=os.environ["BLINK_API_KEY"],
    wallet_id=os.environ["BLINK_WALLET_ID"],
)

@app.get("/api/data")
@l402_required(price_sats=10, lightning=lightning)
async def get_data(request: Request):
    return {"data": "premium content"}
```

<Note>
Python unterstützt auch den **Managed-Modus** — verwenden Sie `ManagedProvider.from_address("you@blink.sv")` (0,3% Gebühr, kein eigener Node erforderlich). Siehe den Abschnitt [Anbieter](#providers) weiter unten.
</Note>

## Flask

```python
import os
from flask import Flask, jsonify
from l402kit import l402_required
from l402kit.providers.blink import BlinkProvider

app = Flask(__name__)

lightning = BlinkProvider(
    api_key=os.environ["BLINK_API_KEY"],
    wallet_id=os.environ["BLINK_WALLET_ID"],
)

@app.route("/api/data")
@l402_required(price_sats=10, lightning=lightning)
def get_data():
    return jsonify({"data": "premium content"})

if __name__ == "__main__":
    app.run(port=3000)
```

<Warning>
**Flask + Gunicorn mit gevent/eventlet-Workern**: `l402_required` ruft den asynchronen Lightning-Anbieter aus einem synchronen Flask-Handler auf. Wenn Ihr Gunicorn-Worker gevent oder eventlet Monkey-Patching verwendet (was einen laufenden Event-Loop erzeugt), erkennt der Decorator dies automatisch und führt den asynchronen Aufruf in einem dedizierten Thread aus — keine Aktion erforderlich. Standardmäßige synchrone Gunicorn-Worker und uvicorn (FastAPI) sind nicht betroffen.
</Warning>

## `@l402_required` — Decorator

### Parameter

| Parameter | Typ | Standard | Beschreibung |
|---|---|---|---|
| `price_sats` | `int` | **erforderlich** | Preis pro Aufruf in satoshis |
| `lightning` | `LightningProvider` | **erforderlich** | Ihr Lightning-Backend |
| `replay` | `ReplayAdapter` | Im Arbeitsspeicher | Austauschbares Replay-Schutz-Backend |

### Verhalten

| Anfrage | Antwort |
|---|---|
| Kein `Authorization`-Header | `402` mit Rechnung, macaroon, Preis |
| Gültiges `L402 <macaroon>:<preimage>` | Handler wird normal ausgeführt |
| Ungültiges oder abgelaufenes Token | `401 Unauthorized` |
| Wiederverwendetes preimage | `401 Token already used` |

### 402-Antwort

```json
{
  "error": "Payment Required",
  "price_sats": 10,
  "invoice": "lnbc100n1...",
  "macaroon": "eyJoYXNoIjoiYWJjMTIzIiwiZXhwIjoxNzAwMDAwMDAwfQ=="
}
```

### `ManagedProvider` — Cloud-Modus (0,3% Gebühr)

l402kit.com betreibt den Lightning-Node. Sie erhalten 99,7% jeder Zahlung — kein eigener Node-Setup erforderlich.

```python
from l402kit import ManagedProvider

lightning = ManagedProvider.from_address("you@blink.sv")

# Optional: im öffentlichen API-Verzeichnis registrieren
lightning = ManagedProvider.from_address("you@blink.sv", register_directory={
    "url": "https://api.you.com/v1/weather",
    "name": "Weather API",
    "price_sats": 10,
    "category": "weather",
})
```

## Replay-Schutz

### Standard — Im Arbeitsspeicher (Entwicklung)

Integriert, keine Konfiguration erforderlich. Wird bei Prozess-Neustart zurückgesetzt.

### Redis (Produktion — Multi-Instanz)

Für Gunicorn/uvicorn-Deployments mit mehreren Workern, teilen Sie den Replay-Status über Redis:

```python
import os, redis
from l402kit import l402_required, RedisReplayAdapter

r = redis.Redis.from_url(os.environ["REDIS_URL"])
replay = RedisReplayAdapter(r, ttl_seconds=86400)

@app.get("/api/data")
@l402_required(
    price_sats=10,
    lightning=lightning,
    replay=replay,
)
async def get_data(request: Request):
    return {"data": "premium content"}
```

`RedisReplayAdapter` verwendet `SET key 1 NX EX ttl` — atomar und frei von Race Conditions.

## Benutzerdefinierter Anbieter

```python
from l402kit.types import LightningProvider, Invoice
import base64, json, time

class MyProvider(LightningProvider):
    async def create_invoice(self, amount_sats: int) -> Invoice:
        result = await my_node.create_invoice(amount_sats)
        exp = int((time.time() + 3600) * 1000)
        macaroon = base64.b64encode(
            json.dumps({"hash": result.hash, "exp": exp}).encode()
        ).decode()
        return Invoice(
            payment_request=result.bolt11,
            payment_hash=result.hash,
            macaroon=macaroon,
            amount_sats=amount_sats,
            expires_at=exp,
        )

    async def check_payment(self, payment_hash: str) -> bool:
        return await my_node.is_paid(payment_hash)
```

## Testen

```python
import hashlib, base64, json, time, os
from l402kit.verify import verify_token

def make_test_token() -> str:
    preimage = os.urandom(32).hex()
    payment_hash = hashlib.sha256(bytes.fromhex(preimage)).hexdigest()
    exp = int((time.time() + 3600) * 1000)
    macaroon = base64.b64encode(
        json.dumps({"hash": payment_hash, "exp": exp}).encode()
    ).decode()
    return f"{macaroon}:{preimage}"

assert verify_token(make_test_token()) is True
```

## L402Client — automatische Zahlung

`L402Client` umschließt `httpx` und verarbeitet den vollständigen 402 → bezahlen → Wiederholung-Ablauf automatisch.

```python
from l402kit import L402Client
from l402kit.wallets import BlinkWallet

wallet = BlinkWallet(
    api_key=os.environ["BLINK_API_KEY"],
    wallet_id=os.environ["BLINK_WALLET_ID"],
)

client = L402Client(wallet=wallet)
data = client.get("https://api.example.com/premium").json()
```

### Wallets

| Klasse | Installation | Beschreibung |
|---|---|---|
| `BlinkWallet` | `pip install l402kit` | Zahlung über [Blink](https://blink.sv) GraphQL-API |
| `AlbyWallet` | `pip install l402kit` | Zahlung über [Alby](https://getalby.com) REST-API |

```python
from l402kit.wallets import BlinkWallet, AlbyWallet

blink = BlinkWallet(api_key="...", wallet_id="...")
alby  = AlbyWallet(access_token=os.environ["ALBY_TOKEN"])
```

## AsyncL402Client — async/await

`AsyncL402Client` verwendet intern `httpx.AsyncClient` — ideal für FastAPI, asyncio und KI-Agent-Frameworks, die in einem asynchronen Event-Loop laufen.

```python
import asyncio
from l402kit import AsyncL402Client
from l402kit.wallets import BlinkWallet

async def main():
    async with AsyncL402Client(
        wallet=BlinkWallet(os.environ["BLINK_API_KEY"], os.environ["BLINK_WALLET_ID"]),
        budget_sats=500,
    ) as client:
        r = await client.get("https://api.example.com/premium")
        print(r.json())

asyncio.run(main())
```

### Unterschied zu `L402Client`

| | `L402Client` | `AsyncL402Client` |
|---|---|---|
| HTTP-Client | `httpx` (synchron) | `httpx.AsyncClient` |
| `get` / `post` | synchron | `async` |
| Geeignet für | Skripte, Flask | FastAPI, asyncio, LangChain `_arun` |
| Budget / Cache | ✅ identisch | ✅ identisch |

## DevProvider + DevWallet — lokale Entwicklung

Konfigurationsfreie lokale Entwicklung — kein Lightning-Node, keine echten Zahlungen. Kryptografisch identisch mit der Produktion: `SHA256(preimage) === paymentHash`.

```python
from l402kit.dev import DevProvider, DevWallet
from l402kit import L402Client, l402_required
from fastapi import FastAPI, Request

app = FastAPI()
provider = DevProvider()
wallet   = DevWallet(provider)

@app.get("/premium")
@l402_required(price_sats=1, lightning=provider)
async def premium(request: Request):
    return {"data": "premium content"}

# Client — zahlt automatisch ohne echtes Lightning
client = L402Client(wallet=wallet)
data   = client.get("http://localhost:8000/premium").json()
```
