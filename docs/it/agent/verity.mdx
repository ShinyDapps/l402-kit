# VERITY

VERITY è un agente AI autonomo costruito su l402-kit. Vende 9 servizi tramite il protocollo L402, accumula una tesoreria in Bitcoin e regola i propri prezzi in base alla domanda — senza intervento umano.

**Endpoint di discovery:** `GET https://l402kit.com/api/verity`

---

## I 9 Servizi

| Servizio | Endpoint | Prezzo | Richiede |
|---|---|---|---|
| Ricerca Web | `/api/verity/search` | 100 sats | — |
| Web Scraping | `/api/verity/scrape` | 200 sats | — |
| Prezzo BTC | `/api/verity/btc-price` | 10 sats | — |
| Riassunto | `/api/verity/summarize` | 50 sats | — |
| Sentiment | `/api/verity/sentiment` | 30 sats | — |
| Domain Intel | `/api/verity/domain-intel` | 500 sats | — |
| Integrazione l402-kit | `/api/verity/integration` | 10.000 sats | — |
| Stato del Mondo | `/api/verity/worldstate` | 80 sats | — |
| Traduzione | `/api/verity/translate` | 50 sats | — |

I prezzi sono dinamici — VERITY li aggiusta ogni 30 minuti in base alla domanda.

---

## Come Pagare

Ogni servizio segue lo standard L402:

```bash
# Passo 1 — richiedi il servizio (ottieni la fattura)
curl -i https://l402kit.com/api/verity/btc-price

# HTTP/1.1 402 Payment Required
# WWW-Authenticate: L402 macaroon="...", invoice="lnbc..."

# Passo 2 — paga la fattura con qualsiasi wallet Lightning
# Passo 3 — riprova con la prova di pagamento
curl -H "Authorization: L402 <macaroon>:<preimage>" \
  https://l402kit.com/api/verity/btc-price
```

## Pagamento automatizzato con L402Client

```typescript
import { L402Client } from "l402-kit/agent";
import { BlinkWallet } from "l402-kit/wallets";

const client = new L402Client({
  wallet: new BlinkWallet(process.env.BLINK_API_KEY!),
  budget: { maxSats: 500 },
});

// Prezzo BTC — 10 sats
const price = await client.fetch("https://l402kit.com/api/verity/btc-price");
const data = await price.json();
console.log(data.bitcoin.usd);

// Stato del mondo — 80 sats
const world = await client.fetch("https://l402kit.com/api/verity/worldstate");
const state = await world.json();
console.log(state.time.utc, state.location.city, state.weather.temperature_c);
```

### Traduzione — 50 sats
Traduce testo o documentazione MDX in una delle 11 lingue supportate. Quando `format` è `mdx`, i blocchi di codice, i componenti MDX, gli URL e i termini tecnici vengono preservati esattamente — viene tradotta solo la prosa.

**Lingue supportate:** `pt`, `es`, `zh`, `ar`, `hi`, `fr`, `de`, `ru`, `ja`, `it`, `en`

```bash
curl -X POST -H "Authorization: L402 <token>" \
  -H "Content-Type: application/json" \
  -d '{"text": "Pay once, access forever.", "locale": "pt", "format": "plain"}' \
  https://l402kit.com/api/verity/translate
```

**Formato MDX** (preserva i blocchi di codice e i componenti):
```bash
curl -X POST -H "Authorization: L402 <token>" \
  -H "Content-Type: application/json" \
  -d '{"text": "---\ntitle: Quickstart\n---\n\nPay with Lightning.", "locale": "ja", "format": "mdx"}' \
  https://l402kit.com/api/verity/translate
```

**Risposta:**
```json
{
  "agent": "VERITY",
  "service": "translate",
  "locale": "pt",
  "language": "Brazilian Portuguese",
  "format": "plain",
  "translated": "Pague uma vez, acesse para sempre.",
  "source_length": 26,
  "paid_with": "⚡ Lightning L402"
}
```

Input massimo: 100.000 caratteri per chiamata.

## Prezzi Dinamici

VERITY aggiusta i prezzi ogni 30 minuti:

```
Alta domanda (> soglia chiamate/ora)      → prezzo × 1.1
Domanda zero (2 ore consecutive)          → prezzo × 0.9
Protezione del minimo                     → il prezzo non scende mai sotto il minimo
```

Controlla i prezzi attuali in qualsiasi momento:
```bash
curl https://l402kit.com/api/verity | jq '.services[].priceSats'
```

## API dell'Operatore

Se effettui il fork di VERITY per eseguire il tuo agente, questi endpoint ti consentono di modificare i prezzi e i budget a runtime — senza alcun deploy.

Tutte le route amministrative richiedono l'intestazione `DASHBOARD_SECRET`:
```
Authorization: Bearer <DASHBOARD_SECRET>
```

### GET /api/verity/admin/config
Restituisce la configurazione attuale dei prezzi e la spesa dei consumatori per tutti i servizi.

```bash
curl -H "Authorization: Bearer <secret>" \
  https://l402kit.com/api/verity/admin/config
```

**Risposta:**
```json
{
  "configs": {
    "search":  { "base": 100, "floor": 50, "surgeThreshold": 50, "cogs": 2 },
    "translate": { "base": 50, "floor": 50, "surgeThreshold": 30, "cogs": 1 }
  },
  "prices": { "search": 100, "translate": 50 },
  "consumer": { "spent_today": 340, "budget": 10000 }
}
```

### POST /api/verity/admin/config
Aggiorna i parametri di prezzo per un servizio specifico. Vengono modificati solo i campi forniti.

```bash
curl -X POST -H "Authorization: Bearer <secret>" \
  -H "Content-Type: application/json" \
  -d '{"service": "search", "base": 150, "floor": 80}' \
  https://l402kit.com/api/verity/admin/config
```

| Campo | Descrizione |
|---|---|
| `service` | Nome del servizio (obbligatorio) |
| `base` | Prezzo base in sats |
| `floor` | Prezzo minimo (il prezzo dinamico non scende mai sotto questo valore) |
| `surgeThreshold` | Chiamate/ora che attivano un aumento del +10% |
| `cogs` | Costo del prodotto in sats (utilizzato dall'agente fiscale) |

### POST /api/verity/admin/budget
Imposta il limite di spesa giornaliera del consumatore.

```bash
curl -X POST -H "Authorization: Bearer <secret>" \
  -H "Content-Type: application/json" \
  -d '{"sats": 5000}' \
  https://l402kit.com/api/verity/admin/budget
```

Minimo: 100 sats. Le modifiche hanno effetto immediato.

## Architettura

```
VERITY (agent:shinydapps.verity)
  ├── 9 servizi protetti da L402
  ├── Tesoreria: shinydapps@blink.sv
  ├── Heartbeat: ogni 30 minuti (aggiustamento prezzi)
  ├── Agente Fiscale: report giornaliero (sats guadagnati + equivalente in BRL)
  └── LAW-N: eventi comportamentali emessi per ogni transazione
```

VERITY è open-source — la stessa architettura può essere forkata per creare il proprio agente autonomo.
