# Exemplos VERITY

VERITY é um agente autônomo ativo em `https://l402kit.com/api/verity`. Estes exemplos mostram como chamar todos os 9 serviços programaticamente usando o SDK de agente do l402-kit.

---

## Configuração

```typescript
import { L402Client } from "l402-kit/agent";
import { BlinkWallet } from "l402-kit/wallets";

const client = new L402Client({
  wallet: new BlinkWallet(process.env.BLINK_API_KEY!),
  budget: { maxSats: 5000 }, // hard cap per session
});
```

---

## Descobrir todos os serviços e preços atuais

```typescript
const res = await fetch("https://l402kit.com/api/verity");
const verity = await res.json();

for (const svc of verity.services) {
  console.log(`${svc.id}: ${svc.priceSats} sats — ${svc.description}`);
}
```

## Estado do Mundo — 80 sats

Obtenha a hora UTC, sua localização e o clima local em uma única chamada.

```typescript
const res = await client.fetch("https://l402kit.com/api/verity/worldstate");
const { time, location, weather } = await res.json();

console.log(`Time: ${time.utc}`);
console.log(`Location: ${location.city}, ${location.country}`);
console.log(`Weather: ${weather.temperature_c}°C, ${weather.condition}`);
```

## Resumir — 50 sats

```typescript
const longText = "..."; // up to 50,000 chars

const res = await client.fetch("https://l402kit.com/api/verity/summarize", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ text: longText, language: "english" }),
```

## Traduzir — 50 sats

Traduza qualquer texto para 11 localidades. O modo com reconhecimento de MDX preserva blocos de código, tags de componentes, URLs e terminologia L402.

```typescript
// Texto simples
const res = await client.fetch("https://l402kit.com/api/verity/translate", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    text: "Pay per call with Bitcoin Lightning. No API keys needed.",
    locale: "pt",
  }),
});
const { translated } = await res.json();
console.log(translated);
// "Pague por chamada com Bitcoin Lightning. Nenhuma chave de API necessária."
```

```typescript
// Com reconhecimento de MDX (preserva blocos de código, <Components />, URLs)
const mdxPage = `## Install\n\`\`\`bash\nnpm install l402-kit\n\`\`\`\nSee [docs](https://docs.l402kit.com).`;

const res = await client.fetch("https://l402kit.com/api/verity/translate", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ text: mdxPage, locale: "es", format: "mdx" }),
});
const { translated } = await res.json();
// Bloco de código e URL preservados intactos; apenas o texto em prosa é traduzido
```

Localidades suportadas: `pt` `es` `zh` `ar` `fr` `de` `ja` `ko` `hi` `ru` `it`

## Integração com l402-kit — 10.000 sats

Envie à VERITY um repositório público do GitHub. Ela lê o código e retorna uma integração completa com o l402-kit.

```typescript
const res = await client.fetch("https://l402kit.com/api/verity/integration", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ repoUrl: "https://github.com/owner/my-api" }),
});
const { integration, next_steps } = await res.json();

// integration = markdown com o código exato a ser adicionado ao seu repositório
console.log(integration);
```

<Note>
O serviço de integração custa 10.000 sats (~$10). Após o pagamento, você recebe o código completo de middleware específico para o seu framework (Express, FastAPI, Gin, Axum, etc.) — e a VERITY ganha a primeira indicação para a sua nova API com l402-kit.
</Note>

## Encadeamento de serviços

Um padrão comum de agente: buscar → extrair → resumir.

```typescript
// 1. Buscar um tópico (100 sats)
const searchRes = await client.fetch(
  "https://l402kit.com/api/verity/search?q=bitcoin+lightning+adoption+2026",
);
const { results } = await searchRes.json();
const topUrl = results[0].link;

// 2. Extrair o primeiro resultado (200 sats)
const scrapeRes = await client.fetch("https://l402kit.com/api/verity/scrape", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ url: topUrl }),
});
const { content } = await scrapeRes.json();

// 3. Resumir o artigo (50 sats)
const sumRes = await client.fetch("https://l402kit.com/api/verity/summarize", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ text: content }),
});
const { summary } = await sumRes.json();

// Custo total: 350 sats (~$0,35)
console.log(summary);
```

## Python

```python
from l402kit import L402Client, BlinkWallet
import os

client = L402Client(
    wallet=BlinkWallet(os.environ["BLINK_API_KEY"]),
    budget={"max_sats": 5000},
)

# Estado do mundo
resp = client.get("https://l402kit.com/api/verity/worldstate")
data = resp.json()
print(f"{data['time']['utc']} | {data['location']['city']} | {data['weather']['temperature_c']}°C")
```
