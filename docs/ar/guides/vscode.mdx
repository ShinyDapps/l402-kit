## الإعداد السريع

1. ثبّت الامتداد من [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=ShinyDapps.shinydapps-l402).
2. افتح لوحة الأوامر (`Ctrl+Shift+P` / `Cmd+Shift+P`).
3. شغّل **ShinyDapps: Configure Lightning Address**.
4. أدخل عنوان Lightning الخاص بك (مثال: `you@blink.sv`).

يضيء عنصر شريط الحالة `⚡ 0 sats (0)` فوراً. يستطلع البيانات كل 30 ثانية ويتحدث تلقائياً.

بدلاً من ذلك، يمكنك تعيينه يدوياً في إعدادات VS Code:

```json
{
  "shinydapps.lightningAddress": "you@blink.sv"
}
```

## ما تراه

### شريط الحالة

`⚡ 1,234 sats (42)` — إجمالي الـ sats المكتسبة وعدد المدفوعات، ظاهر دائماً.
مرّر المؤشر فوق العنصر لرؤية تلميح بالتفاصيل. إذا كنت على الخطة المجانية، يذكّرك التلميح أيضاً بأن Pro يتيح عرض السجل الكامل.

### لوحة Dashboard

انقر على عنصر شريط الحالة أو شغّل **ShinyDapps: Open Dashboard** لفتح اللوحة الكاملة. تحتوي على:

| القسم | الوصف |
|---------|-------------|
| بطاقات الإحصاء | إجمالي المدفوعات، وإجمالي الـ sats، وتقدير USD، وسعر BTC المباشر |
| الرسم البياني الشريطي | الـ sats المكتسبة عبر الزمن (انظر النطاقات أدناه) |
| جدول المدفوعات | آخر 50 معاملة: الطابع الزمني، ونقطة النهاية، والـ sats |
| مؤشر BTC | السعر المباشر من mempool.space، معروض بالـ sat لكل دولار |

تظهر اللوحة أيضاً في الشريط الجانبي (Activity Bar → أيقونة ⚡).

### دعم اللغات

11 لغة مدمجة: English، Português، Español، 中文، 日本語، Français، Deutsch، Русский، हिन्दी، العربية، Italiano. غيّر اللغة عبر القائمة المنسدلة في أعلى لوحة Dashboard.

### الترقية إلى Pro

تكلف Pro **9 دولارات / شهر**، مدفوعة بالبيتكوين عبر Lightning — بدون بطاقة ائتمان، بدون حساب.

انقر على **Upgrade with Bitcoin →** داخل لوحة Dashboard، أو انتقل مباشرةً إلى:

```
https://l402kit.com/api/checkout?address=YOU@DOMAIN.COM&tier=pro
```

تُنشئ صفحة الدفع فاتورة BOLT11، وتعرض رمز QR، وتستطلع الدفع. بمجرد التأكيد، يتفعّل Pro فوراً — دون الحاجة إلى إعادة تشغيل.

<Note>
يتحقق الامتداد من حالة Pro عند بدء التشغيل. إذا كنت قد دفعت للتو، انقر على زر التحديث **↺** في لوحة Dashboard للتفعيل الفوري.
</Note>

## الإشعارات

يُطلق الامتداد إشعار VS Code عندما **تصل أول دفعة** أثناء فتح المحرر:

> ⚡ تم استلام أول دفعة! افتح لوحة Dashboard لمشاهدتها.

انقر على **Open Dashboard** في الإشعار للانتقال مباشرةً إلى اللوحة.

---

## الخصوصية والبيانات

- يقرأ الامتداد بيانات المدفوعات من Supabase باستخدام مفتاح **قابل للنشر (للقراءة فقط)** مقيّد بعنوان Lightning الخاص بك.
- لا يتم تخزين رموز المصادقة محلياً — فقط عنوان Lightning في إعدادات VS Code.
- يمكنك حذف جميع بياناتك في أي وقت عبر **Danger Zone → Delete all my data** داخل لوحة Dashboard. يؤدي ذلك إلى إزالة سجل المدفوعات واشتراك Pro من Supabase.

---

## منطقة الخطر

تتضمن لوحة Dashboard تدفقاً لحذف البيانات بشكل ذاتي:

1. وسّع **Danger Zone** في أسفل لوحة Dashboard.
2. اكتب عنوان Lightning الخاص بك للتأكيد.
3. انقر على **Delete my data**.

يُحذف سجل جميع المدفوعات وصلاحية Pro لذلك العنوان بشكل دائم.
