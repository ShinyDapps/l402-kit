# VERITY

VERITY هي وكيل ذكاء اصطناعي مستقل مبني على l402-kit. تبيع 10 خدمات عبر بروتوكول L402، وتجمع خزينة Bitcoin، وتضبط أسعارها بنفسها بناءً على الطلب — دون تدخل بشري.

**نقطة الاستكشاف:** `GET https://l402kit.com/api/verity`

---

## كيفية الدفع

كل خدمة تتبع معيار L402:

```bash
# الخطوة 1 — طلب الخدمة (الحصول على الفاتورة)
curl -i https://l402kit.com/api/verity/btc-price

# HTTP/1.1 402 Payment Required
# WWW-Authenticate: L402 macaroon="...", invoice="lnbc..."

# الخطوة 2 — ادفع الفاتورة بأي محفظة Lightning
# الخطوة 3 — أعد المحاولة مع إثبات الدفع
curl -H "Authorization: L402 <macaroon>:<preimage>" \
  https://l402kit.com/api/verity/btc-price
```

## الدفع الآلي باستخدام L402Client

```typescript
import { L402Client } from "l402-kit/agent";
import { BlinkWallet } from "l402-kit/wallets";

const client = new L402Client({
  wallet: new BlinkWallet(process.env.BLINK_API_KEY!),
  budget: { maxSats: 500 },
});

// BTC price — 10 sats
const price = await client.fetch("https://l402kit.com/api/verity/btc-price");
const data = await price.json();
console.log(data.bitcoin.usd);

// World state — 80 sats
const world = await client.fetch("https://l402kit.com/api/verity/worldstate");
const state = await world.json();
console.log(state.time.utc, state.location.city, state.weather.temperature_c);
```

```bash

  "https://l402kit.com/api/verity/search?q=bitcoin+lightning"
```

### البحث المعمّق — 300 sats
حزمة بحث شاملة: بحث + استخراج بيانات + تلخيص بالذكاء الاصطناعي في استدعاء واحد. يوفّر 3 مدفوعات منفصلة وثلاثة أضعاف زمن الاستجابة.

```bash
curl -X POST -H "Authorization: L402 <token>" \
  -H "Content-Type: application/json" \

  https://l402kit.com/api/verity/research
```

**الاستجابة:**
```json
{
  "agent": "VERITY",
  "service": "research",
  "query": "bitcoin lightning network adoption 2026",
  "summary": "Lightning Network adoption has accelerated significantly in 2026...",
  "scraped_url": "https://example.com/article",
  "sources": [
    { "title": "...", "link": "...", "snippet": "..." }
  ],
  "provider": "serper",
  "paid_with": "⚡ Lightning L402"
```

**مقارنةً باستدعاء الخدمات بشكل منفصل:** بحث (100 sats) + استخراج بيانات (200 sats) + تلخيص (50 sats) = 350 sats إجمالاً. البحث المعمّق يكلف 300 sats — أرخص ودفعة واحدة.

### الترجمة — 50 sats
تُترجم النصوص أو توثيق MDX إلى أي من 11 لغة مدعومة. عند تحديد `format` بقيمة `mdx`، تُحفظ كتل الكود ومكونات MDX والروابط والمصطلحات التقنية كما هي — ويُترجم النص العادي فقط.

**اللغات المدعومة:** `pt`, `es`, `zh`, `ar`, `hi`, `fr`, `de`, `ru`, `ja`, `it`, `en`

```bash
curl -X POST -H "Authorization: L402 <token>" \
  -H "Content-Type: application/json" \
  -d '{"text": "Pay once, access forever.", "locale": "pt", "format": "plain"}' \
  https://l402kit.com/api/verity/translate
```

**صيغة MDX** (تحفظ كتل الكود والمكونات):
```bash
curl -X POST -H "Authorization: L402 <token>" \
  -H "Content-Type: application/json" \
  -d '{"text": "---\ntitle: Quickstart\n---\n\nPay with Lightning.", "locale": "ja", "format": "mdx"}' \
  https://l402kit.com/api/verity/translate
```

**الاستجابة:**
```json
{
  "agent": "VERITY",
  "service": "translate",
  "locale": "pt",
  "language": "Brazilian Portuguese",
  "format": "plain",
  "translated": "Pague uma vez, acesse para sempre.",
  "source_length": 26,
  "paid_with": "⚡ Lightning L402"

```

الحد الأقصى للإدخال: 100,000 حرف لكل استدعاء.

## التسعير الديناميكي

تضبط VERITY الأسعار كل 30 دقيقة:

```
طلب مرتفع (> حد معين من الاستدعاءات/الساعة) → السعر × 1.1
طلب معدوم (ساعتان متتاليتان)                → السعر × 0.9
حماية الحد الأدنى                            → السعر لا ينخفض أبدًا عن الحد الأدنى
```

تحقق من الأسعار الحالية في أي وقت:
```bash
curl https://l402kit.com/api/verity | jq '.services[].priceSats'
```

## نقاط النهاية العامة للاكتشاف

لا تتطلب هذه النقطتان دفع L402 — تكشفان عن كتالوج VERITY وبياناتها المالية للتدقيق والاكتشاف.

### GET /api/verity/services

كتالوج قابل للقراءة آليًا لجميع الخدمات النشطة مع التسعير الفوري والحد الأدنى وعتبات الزيادة.

```bash
curl https://l402kit.com/api/verity/services
```

```json
{
  "services": [
    {
      "id": "search",
      "endpoint": "https://l402kit.com/api/verity/search",
      "price_sats": 500,
      "floor_sats": 500,
      "cogs_sats": 50,
      "surge_threshold": 50
    }
  ],
  "count": 10,
  "updated": "2026-05-12T14:32:00.000Z"
}
```

التقرير المالي اليومي لـ VERITY — الإيرادات والتكاليف والهامش والتفصيل حسب الخدمة. يُنشأ يوميًا في 00:00 UTC.

```bash

```

## واجهة برمجة المشغّل

إذا قمت بنسخ VERITY لتشغيل وكيلك الخاص، تتيح لك هذه النقاط تغيير التسعير والميزانيات في وقت التشغيل — دون الحاجة إلى نشر جديد.

جميع مسارات الإدارة تتطلب رأس `DASHBOARD_SECRET`:
```
Authorization: Bearer <DASHBOARD_SECRET>
```

### GET /api/verity/admin/config
يُعيد إعدادات التسعير الحالية وإنفاق المستخدم لجميع الخدمات.

```bash
curl -H "Authorization: Bearer <secret>" \
  https://l402kit.com/api/verity/admin/config
```

**الاستجابة:**
```json
{
  "configs": {
    "search":  { "base": 100, "floor": 50, "surgeThreshold": 50, "cogs": 2 },
    "translate": { "base": 50, "floor": 50, "surgeThreshold": 30, "cogs": 1 }
  },
  "prices": { "search": 100, "translate": 50 },
  "consumer": { "spent_today": 340, "budget": 10000 }
}
```

### POST /api/verity/admin/config
يُحدّث معاملات التسعير لخدمة محددة. يُغيَّر فقط الحقول المُدرجة.

```bash
curl -X POST -H "Authorization: Bearer <secret>" \
  -H "Content-Type: application/json" \
  -d '{"service": "search", "base": 150, "floor": 80}' \
  https://l402kit.com/api/verity/admin/config
```

| الحقل | الوصف |
|---|---|
| `service` | اسم الخدمة (مطلوب) |
| `base` | السعر الأساسي بـ sats |
| `floor` | الحد الأدنى للسعر (لا ينخفض عنه التسعير الديناميكي أبدًا) |
| `surgeThreshold` | عدد الاستدعاءات/الساعة الذي يُفعّل زيادة بنسبة 10% |
| `cogs` | تكلفة البضائع بـ sats (تستخدمها الوكالة المالية) |

### POST /api/verity/admin/budget
يضبط حد الإنفاق اليومي للمستخدم.

```bash
curl -X POST -H "Authorization: Bearer <secret>" \
  -H "Content-Type: application/json" \
  -d '{"sats": 5000}' \
  https://l402kit.com/api/verity/admin/budget
```

الحد الأدنى: 100 sats. تسري التغييرات فورًا.

## البنية التقنية

```
VERITY (agent:shinydapps.verity)
  ├── 10 L402-protected services
  ├── Treasury: shinydapps@blink.sv
  ├── Heartbeat: every 30min (price adjustment + Satring market scan)
  ├── Query cache: KV-backed, per-service TTL (5min–24h)
  ├── Fiscal Agent: daily report at 00:00 UTC → GET /api/verity/fiscal
  ├── Service catalog: machine-readable → GET /api/verity/services
  ├── Agent contract: GET /.well-known/agent.json → verity block
  └── LAW-N: behavioral events emitted per transaction
```

VERITY مفتوحة المصدر — يمكن نسخ نفس البنية التقنية لإنشاء وكيلك المستقل الخاص.
