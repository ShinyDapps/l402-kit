## त्वरित सेटअप

1. [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=ShinyDapps.shinydapps-l402) से एक्सटेंशन इंस्टॉल करें।
2. Command Palette खोलें (`Ctrl+Shift+P` / `Cmd+Shift+P`)।
3. **ShinyDapps: Configure Lightning Address** चलाएं।
4. अपना Lightning पता दर्ज करें (उदा. `you@blink.sv`)।

स्टेटस बार आइटम `⚡ 0 sats (0)` तुरंत चमक उठता है। यह हर 30 सेकंड में पोल करता है और स्वचालित रूप से अपडेट होता है।

वैकल्पिक रूप से, इसे अपनी VS Code सेटिंग्स में मैन्युअली सेट करें:

```json
{
  "shinydapps.lightningAddress": "you@blink.sv"
}
```

## आप क्या देखते हैं

### स्टेटस बार

`⚡ 1,234 sats (42)` — कुल अर्जित sats और भुगतान की संख्या, हमेशा दिखाई देती है।
विवरण के साथ एक टूलटिप देखने के लिए आइटम पर होवर करें। यदि आप फ्री प्लान पर हैं, तो टूलटिप आपको यह भी याद दिलाती है कि Pro पूरा इतिहास अनलॉक करता है।

### डैशबोर्ड पैनल

पूरा पैनल खोलने के लिए स्टेटस बार आइटम पर क्लिक करें या **ShinyDapps: Open Dashboard** चलाएं। इसमें शामिल हैं:

| सेक्शन | विवरण |
|---------|-------------|
| स्टैट कार्ड्स | कुल भुगतान, कुल sats, USD अनुमान, लाइव BTC मूल्य |
| बार चार्ट | समय के साथ अर्जित sats (नीचे दिए गए रेंज देखें) |
| पेमेंट्स टेबल | अंतिम 50 लेनदेन: टाइमस्टैम्प, एंडपॉइंट, sats |
| BTC टिकर | mempool.space से लाइव मूल्य, sat-per-dollar में दिखाया गया |

पैनल साइडबार में भी दिखाई देता है (Activity Bar → ⚡ आइकन)।

### भाषा समर्थन

11 भाषाएं अंतर्निहित: English, Português, Español, 中文, 日本語, Français, Deutsch, Русский, हिन्दी, العربية, Italiano। डैशबोर्ड के शीर्ष पर ड्रॉपडाउन के माध्यम से स्विच करें।

### Pro में अपग्रेड करें

Pro की लागत **$9 / माह** है, Lightning पर Bitcoin में भुगतान किया जाता है — कोई क्रेडिट कार्ड नहीं, कोई अकाउंट नहीं।

डैशबोर्ड के अंदर **Upgrade with Bitcoin →** पर क्लिक करें, या सीधे यहाँ जाएं:

```
https://l402kit.com/api/checkout?address=YOU@DOMAIN.COM&tier=pro
```

चेकआउट पेज एक BOLT11 इनवॉइस जेनरेट करता है, एक QR कोड दिखाता है, और भुगतान के लिए पोल करता है। एक बार कन्फर्म होने पर, Pro तुरंत सक्रिय हो जाता है — कोई रीस्टार्ट की आवश्यकता नहीं।

<Note>
एक्सटेंशन स्टार्टअप पर Pro स्टेटस जांचता है। यदि आपने अभी भुगतान किया है, तो तुरंत सक्रिय करने के लिए डैशबोर्ड में **↺** रिफ्रेश बटन पर क्लिक करें।
</Note>

## नोटिफिकेशन

जब एडिटर खुला हो और आपका **पहला भुगतान आए** तो एक्सटेंशन VS Code नोटिफिकेशन फायर करता है:

> ⚡ पहला भुगतान प्राप्त हुआ! इसे देखने के लिए अपना डैशबोर्ड खोलें।

सीधे पैनल पर जाने के लिए नोटिफिकेशन में **Open Dashboard** पर क्लिक करें।

---

## गोपनीयता और डेटा

- एक्सटेंशन आपके Lightning पते पर स्कोप की गई **publishable (read-only)** कुंजी का उपयोग करके Supabase से पेमेंट डेटा पढ़ता है।
- कोई भी ऑथेंटिकेशन टोकन स्थानीय रूप से संग्रहीत नहीं किया जाता — केवल VS Code सेटिंग्स में आपका Lightning पता।
- आप डैशबोर्ड के अंदर **Danger Zone → Delete all my data** के माध्यम से किसी भी समय अपना सारा डेटा हटा सकते हैं। यह Supabase से पेमेंट हिस्ट्री और Pro सब्सक्रिप्शन हटा देता है।

---

## डेंजर ज़ोन

डैशबोर्ड में एक सेल्फ-सर्विस डेटा डिलीशन फ्लो शामिल है:

1. डैशबोर्ड के नीचे **Danger Zone** को एक्सपैंड करें।
2. कन्फर्म करने के लिए अपना Lightning पता टाइप करें।
3. **Delete my data** पर क्लिक करें।

उस पते के लिए सभी पेमेंट हिस्ट्री और Pro एक्सेस स्थायी रूप से हटा दी जाती है।
