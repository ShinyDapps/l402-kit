## Satoshi संदर्भ तालिका

1 sat = Bitcoin का 1/100,000,000 वाँ हिस्सा। सामान्य मूल्य बिंदुओं पर:

| BTC मूल्य | 1 sat | 10 sats | 100 sats | 1,000 sats |
|---|---|---|---|---|
| $50,000 | $0.0005 | $0.005 | $0.05 | $0.50 |
| $80,000 | $0.0008 | $0.008 | $0.08 | $0.80 |
| $100,000 | $0.001 | $0.01 | $0.10 | $1.00 |

Lightning payments की कोई न्यूनतम शुल्क सीमा नहीं होती। 1-sat भुगतान में भेजने वाले को लगभग $0.0005 का खर्च आता है — Stripe ($0.30 न्यूनतम) के साथ यह असंभव है।

## उपयोग मामले के अनुसार मूल्य निर्धारण

| उपयोग मामला | सुझाया गया मूल्य | तर्क |
|---|---|---|
| सरल डेटा क्वेरी (मौसम, विनिमय दर) | 1–10 sats | इतना सस्ता कि अदृश्य हो, फिर भी अर्थपूर्ण |
| प्रीमियम API कॉल (LLM inference, खोज) | 10–100 sats | कंप्यूट लागत को कवर करता है, दुरुपयोग को फ़िल्टर करता है |
| प्रति-दस्तावेज़ / प्रति-फ़ाइल एक्सेस | 50–500 sats | सामग्री मूल्य को दर्शाता है |
| उच्च-मूल्य रिपोर्ट या डेटासेट | 500–5,000 sats | $0.50–$5 माइक्रो-ट्रांज़ैक्शन से प्रतिस्पर्धा करता है |
| रियल-टाइम स्ट्रीमिंग (प्रति चंक) | 1–5 sats | एक स्ट्रीम के दौरान स्वाभाविक रूप से जमा होता है |

ये शुरुआती बिंदु हैं। सही मूल्य वह है जो आपके कॉलर बिना किसी असुविधा के चुकाएंगे।

## कम से शुरू करें, ऊपर बढ़ें

चूँकि शुल्क बदलना कोड की एक लाइन है, लॉन्च के समय कम मूल्य रखने की ओर झुकें:

```typescript
l402({ priceSats: 10, lightning }) // यहाँ से शुरू करें
l402({ priceSats: 100, lightning }) // यदि माँग बनी रहे तो बढ़ाएं
```

VS Code डैशबोर्ड में भुगतान डेटा आपको कॉल वॉल्यूम और राजस्व दिखाता है — इसका उपयोग अंशांकन के लिए करें।

## स्केल पर Managed बनाम Soberano

0.3% managed शुल्क केवल वॉल्यूम पर मायने रखती है:

| मासिक वॉल्यूम | Managed शुल्क | Soberano की बचत |
|---|---|---|
| 1,000 sats | 3 sats | नगण्य |
| 100,000 sats | 300 sats (~$0.24) | छोटी |
| 10,000,000 sats | 30,000 sats (~$24) | स्विच करने लायक |

**सामान्य नियम:** यदि आप प्रति माह 1M sats से कम (~$800 at $80k/BTC) प्रोसेस कर रहे हैं, तो 0.3% शुल्क नगण्य है। Managed पर रहें और निर्माण पर ध्यान दें। Soberano पर तब स्विच करें जब वॉल्यूम इसे उचित ठहराए — यह कोड की एक लाइन है।

## AI एजेंट्स के लिए मूल्य निर्धारण

एजेंट मनुष्यों से अलग तरीके से मूल्य के प्रति असंवेदनशील होते हैं — वे भुगतान का दर्द महसूस नहीं करते, लेकिन उनके ऑपरेटरों द्वारा निर्धारित बजट सीमाएँ होती हैं।

**व्यावहारिक मार्गदर्शन:**
- सामान्य एजेंट उपयोग के लिए प्रति कॉल 100 sats से कम मूल्य रखें — यह सामान्य प्रति-सत्र बजट में फिट बैठता है
- उच्च-मूल्य एजेंट टूल्स (कोड निष्पादन, दस्तावेज़ विश्लेषण) के लिए, 100–1,000 sats स्वीकार्य है
- यदि आपकी लागत इनपुट आकार के अनुसार बदलती है तो `priceSats` को गतिशील रूप से उपयोग करें:

```typescript
app.post("/analyze", (req, res, next) => {
  const sats = Math.ceil(req.body.text.length / 100); // 1 sat per 100 chars
  l402({ priceSats: sats, lightning })(req, res, next);
}, handler);
```

## एकाधिक एंडपॉइंट के साथ स्तरीय एक्सेस

विभिन्न एंडपॉइंट पर रूट करके विभिन्न स्तरों का मूल्य निर्धारित करें:

```typescript
// Free tier — basic data
app.get("/data/basic", handler);

// Paid tier — full dataset, 10 sats
app.get("/data/premium", l402({ priceSats: 10, lightning }), handler);

// High-value tier — real-time feed, 100 sats
app.get("/data/realtime", l402({ priceSats: 100, lightning }), handler);
```

प्रत्येक एंडपॉइंट अपना खुद का इनवॉइस जेनरेट करता है। कॉलर प्रति कॉल भुगतान करते हैं — कोई सदस्यता प्रबंधन नहीं।

## अपना मूल्य निर्धारण परखना

लाइव जाने से पहले, एक वास्तविक वॉलेट के साथ पूरे भुगतान प्रवाह का परीक्षण करें:

1. `priceSats: 1` सेट करें (1 sat ≈ $0.0008 — स्वतंत्र रूप से परीक्षण के लिए काफी सस्ता)
2. अपने फ़ोन पर [Wallet of Satoshi](https://walletofsatoshi.com) या [Blink](https://dashboard.blink.sv) का उपयोग करें
3. अपना एंडपॉइंट कॉल करें, इनवॉइस QR स्कैन करें, 200 OK सत्यापित करें
4. प्राप्ति की पुष्टि के लिए [VS Code डैशबोर्ड](https://marketplace.visualstudio.com/items?itemName=ShinyDapps.shinydapps-l402) या अपना Lightning वॉलेट जाँचें

पुष्टि हो जाने के बाद, अपना वास्तविक मूल्य सेट करें और डिप्लॉय करें।
