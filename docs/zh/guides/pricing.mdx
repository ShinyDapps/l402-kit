## Satoshi 参考表

1 sat = 比特币的 1/100,000,000。在常见价格点下：

| BTC 价格 | 1 sat | 10 sats | 100 sats | 1,000 sats |
|---|---|---|---|---|
| $50,000 | $0.0005 | $0.005 | $0.05 | $0.50 |
| $80,000 | $0.0008 | $0.008 | $0.08 | $0.80 |
| $100,000 | $0.001 | $0.01 | $0.10 | $1.00 |

Lightning 支付没有最低手续费门槛。一笔 1-sat 的支付对发送方来说约为 $0.0005——这在 Stripe（最低 $0.30）下是不可能实现的。

## 按使用场景定价

| 使用场景 | 建议价格 | 理由 |
|---|---|---|
| 简单数据查询（天气、汇率） | 1–10 sats | 低廉到几乎无感，但仍有实际意义 |
| 高级 API 调用（LLM 推理、搜索） | 10–100 sats | 覆盖计算成本，过滤滥用 |
| 按文档/文件访问计费 | 50–500 sats | 体现内容价值 |
| 高价值报告或数据集 | 500–5,000 sats | 与 $0.50–$5 的微交易相竞争 |
| 实时流式传输（按数据块计费） | 1–5 sats | 在流式传输过程中自然累积 |

以上仅为起点。正确的价格是调用方愿意无阻力支付的价格。

## 从低价开始，逐步提升

由于调整费用只需修改一行代码，建议在上线时偏向低价：

```typescript
l402({ priceSats: 10, lightning }) // 从这里开始
l402({ priceSats: 100, lightning }) // 若需求稳定则提价
```

VS Code 控制台中的支付数据会显示调用量和收入——利用这些数据进行校准。

## 大规模场景下的 Managed 与 Soberano 对比

0.3% 的 Managed 手续费只有在大规模使用时才有明显影响：

| 月交易量 | Managed 手续费 | Soberano 节省金额 |
|---|---|---|
| 1,000 sats | 3 sats | 可忽略不计 |
| 100,000 sats | 300 sats（约 $0.24） | 较小 |
| 10,000,000 sats | 30,000 sats（约 $24） | 值得切换 |

**经验法则：** 如果你每月处理的交易量低于 1M sats（按 $80k/BTC 计算约为 $800），0.3% 的手续费几乎可以忽略不计。继续使用 Managed 专注于构建产品，当交易量达到值得切换的规模时再迁移到 Soberano——只需修改一行代码。

## 为 AI 智能体定价

智能体对价格不敏感的方式与人类不同——它们感受不到付款的"痛苦"，但其运营者会为其设置预算上限。

**实用建议：**
- 针对一般智能体使用场景，每次调用的价格保持在 100 sats 以下——这符合典型的单次会话预算
- 对于高价值智能体工具（代码执行、文档分析），100–1,000 sats 是可以接受的
- 如果你的成本随输入大小变化，可动态使用 `priceSats`：

```typescript
app.post("/analyze", (req, res, next) => {
  const sats = Math.ceil(req.body.text.length / 100); // 每 100 个字符 1 sat
  l402({ priceSats: sats, lightning })(req, res, next);
}, handler);
```

## 通过多端点实现分级访问

通过路由到不同端点来对不同层级进行定价：

```typescript
// 免费层级——基础数据
app.get("/data/basic", handler);

// 付费层级——完整数据集，10 sats
app.get("/data/premium", l402({ priceSats: 10, lightning }), handler);

// 高价值层级——实时数据流，100 sats
app.get("/data/realtime", l402({ priceSats: 100, lightning }), handler);
```

每个端点会生成各自的发票。调用方按次付费——无需管理订阅。

## 测试你的定价

上线前，使用真实钱包测试完整的支付流程：

1. 设置 `priceSats: 1`（1 sat ≈ $0.0008——低廉到可以自由测试）
2. 在手机上使用 [Wallet of Satoshi](https://walletofsatoshi.com) 或 [Blink](https://dashboard.blink.sv)
3. 调用你的端点，扫描发票二维码，验证返回 200 OK
4. 查看 [VS Code 控制台](https://marketplace.visualstudio.com/items?itemName=ShinyDapps.shinydapps-l402) 或你的 Lightning 钱包以确认收款

确认无误后，设置正式价格并部署。
