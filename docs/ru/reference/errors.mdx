description: "Семантические коды ошибок из l402-kit для агентов и разработчиков."
---

Все ошибки из l402-kit следуют структурированному формату JSON, чтобы агенты могли разбирать их и реагировать на них программно.

```json
{
  "error": "ERROR_CODE",
  "code": 402,
  "cause": "Human-readable explanation",
  "action": "recommended_action",
  "retry": false
}
```

---

## Коды ошибок

### PAYMENT_FAILED

```json
{
  "error": "PAYMENT_FAILED",
  "code": 402,
  "cause": "Insufficient balance in wallet",
  "action": "increase_budget",
  "retry": false
}
```

Кошелёк не смог оплатить инвойс. Проверьте баланс и лимит `budgetSats`.

---

### TOKEN_EXPIRED

```json
{
  "error": "TOKEN_EXPIRED",
  "code": 402,
  "cause": "Macaroon expiry timestamp exceeded",
  "action": "request_new_invoice",
  "retry": true
}
```

Токен L402 был создан, но не использован до истечения TTL (по умолчанию: 1 час). Повторите запрос, чтобы получить новый инвойс.

---

### BUDGET_EXCEEDED

```json
{
  "error": "BUDGET_EXCEEDED",
  "code": 402,
  "cause": "Session budget of {n} sats exhausted",
  "action": "stop_or_increase_budget",
  "retry": false
}
```

Агент потратил больше, чем `budgetSats` в текущей сессии. Увеличьте бюджет или завершите сессию.

---

### INVALID_MACAROON

```json
{
  "error": "INVALID_MACAROON",
  "code": 402,
  "cause": "Macaroon is not valid base64 JSON",
  "action": "request_new_invoice",
  "retry": true
}
```

macaroon не удалось декодировать. Обычно это вызвано повреждённым токеном. Повторите попытку с нуля.

---

### TOKEN_ALREADY_USED

```json
{
  "error": "TOKEN_ALREADY_USED",
  "code": 401,
  "cause": "Preimage was already presented — replay attack blocked",
  "action": "do_not_retry",
  "retry": false
}
```

Сработала защита от повторного использования. Каждый preimage может быть использован только один раз. Никогда не используйте токены повторно.

---

### NODE_UNREACHABLE

```json
{
  "error": "NODE_UNREACHABLE",
  "code": 503,
  "cause": "Lightning node did not respond within timeout",
  "action": "retry_with_backoff",
  "retry": true
}
```

Lightning-провайдер недоступен. Повторите попытку с экспоненциальной задержкой.

---

### INVOICE_EXPIRED

```json
{
  "error": "INVOICE_EXPIRED",
  "code": 402,
  "cause": "BOLT11 invoice expired before payment was submitted",
  "action": "request_new_invoice",
  "retry": true
}
```

BOLT11 инвойсы истекают (по умолчанию: 600 секунд). Повторите исходный запрос, чтобы получить новый инвойс.

---

### WRONG_PREIMAGE

```json
{
  "error": "WRONG_PREIMAGE",
  "code": 402,
  "cause": "SHA256(preimage) does not match paymentHash in macaroon",
  "action": "check_wallet_payment",
  "retry": false
}
```

Криптографическая проверка не пройдена. preimage не подтверждает оплату данного инвойса.

## Обработка ошибок в агентах

```typescript
import { l402 } from "l402-kit/agent";

try {
  const res = await client.fetch("https://api.example.com/data");
} catch (err: any) {
  if (err.error === "BUDGET_EXCEEDED") {
    // stop and report to user
  } else if (err.retry === true) {
    // safe to retry after short delay
    await sleep(1000);
    const res = await client.fetch("https://api.example.com/data");
  }
}
```
