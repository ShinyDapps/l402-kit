## Быстрая настройка

1. Установите расширение из [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=ShinyDapps.shinydapps-l402).
2. Откройте палитру команд (`Ctrl+Shift+P` / `Cmd+Shift+P`).
3. Выполните команду **ShinyDapps: Configure Lightning Address**.
4. Введите свой Lightning-адрес (например, `you@blink.sv`).

Элемент строки состояния `⚡ 0 sats (0)` загорается сразу же. Опрос выполняется каждые 30 секунд, данные обновляются автоматически.

Также можно задать адрес вручную в настройках VS Code:

```json
{
  "shinydapps.lightningAddress": "you@blink.sv"
}
```

## Что отображается

### Строка состояния

`⚡ 1,234 sats (42)` — суммарное количество заработанных sats и число платежей, всегда на виду.
Наведите курсор на элемент, чтобы увидеть подсказку с подробностями. Если вы используете бесплатный план, подсказка также напомнит, что Pro открывает полную историю.

### Панель управления

Нажмите на элемент строки состояния или выполните команду **ShinyDapps: Open Dashboard**, чтобы открыть полную панель. Она содержит:

| Раздел | Описание |
|--------|----------|
| Карточки статистики | Общее число платежей, суммарные sats, оценка в USD, текущая цена BTC |
| Столбчатый график | Заработанные sats за период (см. диапазоны ниже) |
| Таблица платежей | Последние 50 транзакций: время, эндпоинт, sats |
| Тикер BTC | Актуальная цена с mempool.space, отображается в sat-per-dollar |

Панель также доступна на боковой панели (Activity Bar → значок ⚡).

### Поддержка языков

11 встроенных языков: English, Português, Español, 中文, 日本語, Français, Deutsch, Русский, हिन्दी, العربية, Italiano. Переключение осуществляется через выпадающий список в верхней части панели управления.

| Функция | Бесплатно | Pro |
|---------|-----------|-----|
| История платежей | Последние 30 дней | За всё время |
| Диапазоны графика | 1D · 7D | 1D · 7D · 30D · 1Y · ALL |
| Экспорт в CSV | — | ✓ |
| Строка состояния + живой опрос | ✓ | ✓ |
| Тикер цены BTC | ✓ | ✓ |
| Языки | 11 | 11 |

### Переход на Pro

Pro стоит **$9 в месяц**, оплата в Bitcoin через Lightning — без банковской карты, без учётной записи.

Нажмите **Upgrade with Bitcoin →** внутри панели управления или перейдите напрямую по адресу:

```
https://l402kit.com/api/checkout?address=YOU@DOMAIN.COM&tier=pro
```

Страница оформления заказа генерирует BOLT11-инвойс, показывает QR-код и ожидает оплаты. После подтверждения Pro активируется мгновенно — перезапуск не требуется.

<Note>
Расширение проверяет статус Pro при запуске. Если вы только что оплатили, нажмите кнопку **↺** обновления в панели управления для немедленной активации.
</Note>

## Конфиденциальность и данные

- Расширение считывает данные о платежах из Supabase, используя **публичный (только для чтения)** ключ, привязанный к вашему Lightning-адресу.
- Никакие токены аутентификации не хранятся локально — только ваш Lightning-адрес в настройках VS Code.
- Вы можете удалить все свои данные в любой момент через **Danger Zone → Delete all my data** внутри панели управления. Это удаляет историю платежей и Pro-подписку из Supabase.

---

## Опасная зона

Панель управления включает самостоятельный процесс удаления данных:

1. Разверните раздел **Danger Zone** в нижней части панели управления.
2. Введите свой Lightning-адрес для подтверждения.
3. Нажмите **Delete my data**.

Вся история платежей и Pro-доступ для этого адреса будут удалены безвозвратно.
