## Что такое MCP?

[Model Context Protocol](https://modelcontextprotocol.io) — открытый стандарт Anthropic для предоставления LLM доступа к внешним инструментам. l402-kit поставляется с готовым MCP-сервером с двумя категориями инструментов:

### Универсальные L402-инструменты

| Инструмент | Описание |
|------|-------------|
| `l402_fetch` | Запрос к любому URL — автоматически оплачивает, если возвращается 402 |
| `l402_balance` | Проверка оставшегося Lightning-бюджета |
| `l402_spending_report` | Полная разбивка платежей за текущую сессию |

### Инструменты VERITY — платные сервисы с автоматической оплатой

| Инструмент | Цена | Описание |
|------|------:|-------------|
| `verity_btc_price` | 10 sats | Цена BTC в реальном времени в USD, EUR, BRL |
| `verity_worldstate` | 80 sats | Время UTC + геолокация + местная погода |
| `verity_search` | 100 sats | Веб-поиск, топ 10 органических результатов |
| `verity_summarize` | 50 sats | ИИ-суммаризация до 50 000 символов |
| `verity_sentiment` | 30 sats | Оценка тональности + ключевые слова |
| `verity_scrape` | 200 sats | Веб-скрапинг с преобразованием в чистый markdown |
| `verity_domain_intel` | 500 sats | WHOIS + DNS + SSL-сертификаты |
| `verity_integration` | 10 000 sats | Полная интеграция l402-kit для любого GitHub-репозитория |

Инструменты VERITY оплачиваются автономно — ручная обработка инвойсов не требуется.

## Настройка в Claude Desktop

### 1. Установите Node.js ≥ 18

### 2. Настройте кошелёк

<Tabs>
  <Tab title="Blink">
    Отредактируйте `claude_desktop_config.json`:

    ```json
    {
      "mcpServers": {
        "l402": {
          "command": "npx",
          "args": ["l402-kit-mcp"],
          "env": {
            "BLINK_API_KEY": "your-blink-api-key",
            "BLINK_WALLET_ID": "your-wallet-id",
            "BUDGET_SATS": "2000"
          }
        }
      }
    }
    ```
  </Tab>
  <Tab title="Alby">
    ```json
    {
      "mcpServers": {
        "l402": {
          "command": "npx",
          "args": ["l402-kit-mcp"],
          "env": {
            "ALBY_TOKEN": "your-alby-access-token",
            "BUDGET_SATS": "2000"
          }
        }
      }
    }
    ```

    Для самостоятельно размещённого Alby Hub добавьте:
    ```json
    "ALBY_HUB_URL": "https://your-hub.example.com"
    ```
  </Tab>
</Tabs>

**Расположение файла конфигурации:**
- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

### 3. Перезапустите Claude Desktop

Инструменты `l402_fetch`, `l402_balance` и `l402_spending_report` появятся в списке инструментов Claude.

## Переменные окружения

| Переменная | Обязательная | Описание |
|----------|:--------:|-------------|
| `BLINK_API_KEY` | только Blink | Ваш API-ключ Blink |
| `BLINK_WALLET_ID` | только Blink | Идентификатор вашего кошелька Blink |
| `ALBY_TOKEN` | только Alby | Токен доступа Alby |
| `ALBY_HUB_URL` | необязательная | Базовый URL кастомного Alby Hub |
| `BUDGET_SATS` | необязательная | Максимальные расходы за сессию (по умолчанию: `2000`) |

## Использование инструментов

После запуска сервера Claude может автономно вызывать VERITY и любой L402-защищённый API:

```
Вы: Какова цена BTC прямо сейчас?

Claude: [вызывает verity_btc_price]
        [Оплачено 10 sats] {"bitcoin":{"usd":97500,"eur":89800,"brl":548000}}

        Биткоин сейчас стоит $97 500 USD (Стоимость: 10 sats)
```

```
Вы: Кратко изложи эту статью: <вставляет 5 000 слов>

Claude: [вызывает verity_summarize с text="..."]
        [Оплачено 50 sats] {"summary":"..."}
```

```
Вы: Найди "lightning network adoption 2026"

Claude: [вызывает verity_search с q="lightning network adoption 2026"]
        [Оплачено 100 sats] {"results":[...]}
```

```
Вы: Сколько я потратил за это время?

Claude: [вызывает l402_spending_report]
        === L402 Spending Report ===
        Total spent:  160 sats
        Remaining:    1840 sats

        By domain:
          l402kit.com: 160 sats
```

## Настройка с любым MCP-клиентом

Сервер читает из `stdin` и пишет в `stdout` (stdio-транспорт):

```bash
BLINK_API_KEY=xxx BLINK_WALLET_ID=yyy BUDGET_SATS=500 npx l402-kit-mcp
```

Любой MCP-совместимый клиент может подключиться через stdio-транспорт.

## Создание кастомного MCP-сервера

Вы также можете встроить `L402Client` непосредственно в собственный MCP-сервер:

```typescript
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { L402Client, BlinkWallet } from "l402-kit";
import { z } from "zod";

const client = new L402Client({
  wallet: new BlinkWallet(process.env.BLINK_API_KEY!, process.env.BLINK_WALLET_ID!),
  budgetSats: 1000,
});

const server = new McpServer({ name: "my-agent", version: "1.0.0" });

server.tool(
  "fetch_weather",
  "Get current weather for a city — pays automatically",
  { city: z.string() },
  async ({ city }) => {
    const res = await client.fetch(`https://api.weather.com/current?city=${city}`);
    const text = await res.text();
    return { content: [{ type: "text", text }] };
  },
);

const transport = new StdioServerTransport();
await server.connect(transport);
```

## Примечания по безопасности

- Ограничение бюджета (`BUDGET_SATS`) — ваша основная защита; устанавливайте его консервативно
- Каждый процесс `npx l402-kit-mcp` имеет собственный бюджет в оперативной памяти; он сбрасывается при перезапуске
- Для продакшн-агентов сохраняйте журнал расходов через коллбэк `onSpend` во внешнее хранилище
