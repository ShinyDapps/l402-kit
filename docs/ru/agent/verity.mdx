# VERITY

VERITY — это автономный ИИ-агент, построенный на l402-kit. Она продаёт 10 сервисов через протокол L402, накапливает Bitcoin-казну и самостоятельно корректирует цены в зависимости от спроса — без участия человека.

**Endpoint для обнаружения:** `GET https://l402kit.com/api/verity`

---

## 10 сервисов

| Сервис | Endpoint | Цена | Требования |
|---|---|---|---|
| Веб-поиск | `/api/verity/search` | 100 sats | — |
| Веб-скрапинг | `/api/verity/scrape` | 200 sats | — |
| Курс BTC | `/api/verity/btc-price` | 10 sats | — |
| Суммаризация | `/api/verity/summarize` | 50 sats | — |
| Тональность | `/api/verity/sentiment` | 30 sats | — |
| Информация о домене | `/api/verity/domain-intel` | 500 sats | — |
| Интеграция l402-kit | `/api/verity/integration` | 10 000 sats | — |
| Состояние мира | `/api/verity/worldstate` | 80 sats | — |
| Перевод | `/api/verity/translate` | 50 sats | — |
| Исследование | `/api/verity/research` | 300 sats | — |

Цены динамические — VERITY корректирует их каждые 30 минут в зависимости от спроса.

## Как оплатить

Каждый сервис следует стандартному L402:

```bash
# Шаг 1 — запросить сервис (получить инвойс)
curl -i https://l402kit.com/api/verity/btc-price

# HTTP/1.1 402 Payment Required
# WWW-Authenticate: L402 macaroon="...", invoice="lnbc..."

# Шаг 2 — оплатить инвойс любым Lightning-кошельком
# Шаг 3 — повторить запрос с подтверждением оплаты
curl -H "Authorization: L402 <macaroon>:<preimage>" \
  https://l402kit.com/api/verity/btc-price
```

## Автоматическая оплата через L402Client

```typescript
import { L402Client } from "l402-kit/agent";
import { BlinkWallet } from "l402-kit/wallets";

const client = new L402Client({
  wallet: new BlinkWallet(process.env.BLINK_API_KEY!),
  budget: { maxSats: 500 },
});

// Курс BTC — 10 sats
const price = await client.fetch("https://l402kit.com/api/verity/btc-price");
const data = await price.json();
console.log(data.bitcoin.usd);

// Состояние мира — 80 sats
const world = await client.fetch("https://l402kit.com/api/verity/worldstate");
const state = await world.json();
console.log(state.time.utc, state.location.city, state.weather.temperature_c);
```

```bash
# GET
curl -H "Authorization: L402 <token>" \
  "https://l402kit.com/api/verity/search?q=bitcoin+lightning"

# POST
curl -X POST -H "Authorization: L402 <token>" \
  -H "Content-Type: application/json" \
  -d '{"q":"bitcoin lightning"}' \
```

### Исследование — 300 sats
Комплексное исследование: поиск + скрапинг + ИИ-суммаризация в одном запросе. Экономит 3 отдельных платежа и троекратную задержку при обращениях.

```bash
curl -X POST -H "Authorization: L402 <token>" \
  -H "Content-Type: application/json" \
  -d '{"query": "bitcoin lightning network adoption 2026"}' \
  https://l402kit.com/api/verity/research
```

**Ответ:**
```json
{
  "agent": "VERITY",
  "service": "research",
  "query": "bitcoin lightning network adoption 2026",
  "summary": "Lightning Network adoption has accelerated significantly in 2026...",
  "scraped_url": "https://example.com/article",
  "sources": [
    { "title": "...", "link": "...", "snippet": "..." }
  ],
  "provider": "serper",
  "paid_with": "⚡ Lightning L402"
}
```

**В сравнении с раздельными вызовами:** Поиск (100 sats) + Скрапинг (200 sats) + Суммаризация (50 sats) = 350 sats итого. Исследование стоит 300 sats — дешевле и один платёж.

### Перевод — 50 sats
Переводит текст или MDX-документацию на любой из 11 поддерживаемых языков. Когда `format` равен `mdx`, блоки кода, MDX-компоненты, URL и технические термины сохраняются без изменений — переводится только основной текст.

**Поддерживаемые локали:** `pt`, `es`, `zh`, `ar`, `hi`, `fr`, `de`, `ru`, `ja`, `it`, `en`

```bash
curl -X POST -H "Authorization: L402 <token>" \
  -H "Content-Type: application/json" \
  -d '{"text": "Pay once, access forever.", "locale": "pt", "format": "plain"}' \
  https://l402kit.com/api/verity/translate
```

**Формат MDX** (сохраняет блоки кода и компоненты):
```bash
curl -X POST -H "Authorization: L402 <token>" \
  -H "Content-Type: application/json" \
  -d '{"text": "---\ntitle: Quickstart\n---\n\nPay with Lightning.", "locale": "ja", "format": "mdx"}' \
  https://l402kit.com/api/verity/translate
```

**Ответ:**
```json
{
  "agent": "VERITY",
  "service": "translate",
  "locale": "pt",
  "language": "Brazilian Portuguese",
  "format": "plain",
  "translated": "Pague uma vez, acesse para sempre.",
  "source_length": 26,
  "paid_with": "⚡ Lightning L402"
}
```

Максимальный объём входных данных: 100 000 символов за вызов.

## Динамическое ценообразование

VERITY корректирует цены каждые 30 минут:

```
Высокий спрос (> порогового числа вызовов/час) → цена × 1.1
Нулевой спрос (2 последовательных часа)        → цена × 0.9
Защита минимума                                → цена никогда не опускается ниже минимума
```

Проверить актуальные цены в любой момент:
```bash
curl https://l402kit.com/api/verity | jq '.services[].priceSats'
```

## Публичные эндпоинты обнаружения

Эти два эндпоинта не требуют L402-оплаты — они открывают каталог и финансы VERITY для аудита и обнаружения.

### GET /api/verity/services

Машиночитаемый каталог всех активных сервисов с актуальными ценами, минимальными ценами и порогами сёрджа.

```bash
curl https://l402kit.com/api/verity/services
```

```json
{
  "services": [
    {
      "id": "search",
      "endpoint": "https://l402kit.com/api/verity/search",
      "price_sats": 500,
      "floor_sats": 500,
      "cogs_sats": 50,
      "surge_threshold": 50
    }
  ],
  "count": 10,
  "updated": "2026-05-12T14:32:00.000Z"
}
```

### GET /api/verity/fiscal

Ежедневный финансовый отчёт VERITY — доходы, затраты, маржа и разбивка по сервисам. Генерируется в 00:00 UTC.

```bash
curl https://l402kit.com/api/verity/fiscal
```

```json
{
  "date": "2026-05-12",
  "agent": "VERITY",
  "revenue_sats": 8450,
  "consumer_spent_sats": 340,
  "net_sats": 8110,
  "margin_pct": "95.98",
  "brl_equivalent": "50.70",
  "btc_brl_rate": 600000,
  "breakdown": {
    "search": { "calls": 21, "price": 500, "revenue": 10500, "success_rate": 98 }
  },
  "generated_at": "2026-05-12T00:00:01.000Z"
}
```

Отчёты хранятся 7 дней. Возвращает 404, если отчёт за день ещё не сгенерирован.

## API оператора

Если вы создаёте форк VERITY для запуска собственного агента, эти endpoint'ы позволяют изменять цены и бюджеты в режиме реального времени — без повторного развёртывания.

Все административные маршруты требуют заголовка `DASHBOARD_SECRET`:
```
Authorization: Bearer <DASHBOARD_SECRET>
```

### GET /api/verity/admin/config
Возвращает текущую конфигурацию цен и расходы потребителя по всем сервисам.

```bash
curl -H "Authorization: Bearer <secret>" \
  https://l402kit.com/api/verity/admin/config
```

**Ответ:**
```json
{
  "configs": {
    "search":  { "base": 100, "floor": 50, "surgeThreshold": 50, "cogs": 2 },
    "translate": { "base": 50, "floor": 50, "surgeThreshold": 30, "cogs": 1 }
  },
  "prices": { "search": 100, "translate": 50 },
  "consumer": { "spent_today": 340, "budget": 10000 }
}
```

### POST /api/verity/admin/config
Обновляет параметры ценообразования для конкретного сервиса. Изменяются только переданные поля.

```bash
curl -X POST -H "Authorization: Bearer <secret>" \
  -H "Content-Type: application/json" \
  -d '{"service": "search", "base": 150, "floor": 80}' \
  https://l402kit.com/api/verity/admin/config
```

| Поле | Описание |
|---|---|
| `service` | Название сервиса (обязательно) |
| `base` | Базовая цена в sats |
| `floor` | Минимальная цена (динамическое ценообразование никогда не опускается ниже) |
| `surgeThreshold` | Количество вызовов/час, при котором срабатывает надбавка +10% |
| `cogs` | Себестоимость в sats (используется финансовым агентом) |

### POST /api/verity/admin/budget
Устанавливает дневной лимит расходов потребителя.

```bash
curl -X POST -H "Authorization: Bearer <secret>" \
  -H "Content-Type: application/json" \
  -d '{"sats": 5000}' \
  https://l402kit.com/api/verity/admin/budget
```

Минимум: 100 sats. Изменения вступают в силу немедленно.

## Архитектура

```
VERITY (agent:shinydapps.verity)
  ├── 10 сервисов, защищённых L402
  ├── Казна: shinydapps@blink.sv
  ├── Heartbeat: каждые 30 мин (корректировка цен + сканирование рынка Satring)
  ├── Кэш запросов: на основе KV, TTL по сервису (5 мин – 24 ч)
  ├── Финансовый агент: ежедневный отчёт в 00:00 UTC → GET /api/verity/fiscal
  ├── Каталог сервисов: machine-readable → GET /api/verity/services
  ├── Контракт агента: GET /.well-known/agent.json → блок verity
  └── LAW-N: поведенческие события, генерируемые при каждой транзакции
```

VERITY имеет открытый исходный код — эту же архитектуру можно форкнуть для создания собственного автономного агента.
